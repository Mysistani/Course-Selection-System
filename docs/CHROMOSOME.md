# مدل کروموزوم — مرحله دوم

کروموزوم شامل `sections` و `enrollments` است؛ یک جواب کامل پیشنهادی برای دانشکده، مستقل از تعداد افراد یا نام رشته‌ها. مدل در `src/scheduler/chromosome.py` ساخته شده است. تولید تصادفی جمعیت و Fitness هنوز پیاده نشده‌اند.

## مثال مطابق ساختار پیشنهادی کاربر

```python
from scheduler.chromosome import SectionGene, Chromosome

section = SectionGene(
    section_id='CE301-01',
    course_id='CE301',
    active=True,
    professor_id='P001',
    room_id='ENG-106',
    meeting_slots=[('Saturday', 'T1'), ('Monday', 'T2')],
)
candidate = Chromosome(
    sections={section.section_id: section},
    enrollments={('S001', 'CE301'): section.section_id},
)
```

این مثال نمایشی است؛ شناسه‌ها باید در دیتاست انتخاب‌شده واقعاً موجود باشند. برای کروموزوم کامل، همه کلیدهای درخواست ورودی باید در enrollments باشند؛ درخواست بی‌پاسخ با None حفظ می‌شود.

جلسات همان زوج روز/بازه پیشنهادی کاربر هستند، با نام `SlotKey` تا با کلاس Slot تداخل نام نداشته باشد. هر زوج به ردیف TimeSlots وصل می‌شود؛ زمان شروع/پایان در ژن تکرار نمی‌شود. در سازنده list قابل دریافت است ولی داخل SectionGene به tuple تغییرناپذیر تبدیل می‌شود. تغییر یک گروه با `dataclasses.replace` و سپس `candidate.replace_section(...)` انجام می‌شود. این قرارداد جلوی تغییر پنهانی جلسات و باقی‌ماندن نمره قدیمی را می‌گیرد.

## ساخت جایگاه‌های اولیه

`build_empty_chromosome(dataset)` جایگاه‌های دارای شناسه پایدار را ایجاد می‌کند؛ همه غیرفعال و همه درخواست‌ها None هستند. برآورد پیش‌فرض تعداد جایگاه هر درس از تقاضای همان درس و MinSectionSize آن محاسبه می‌شود: floor(demand/minimum). تعداد ثابت یا رشته خاصی در کد وجود ندارد.

این سقف مربوط به گروه غیرخالی در جواب معتبر است؛ دستور حذف درخواست یا توقف توسعه نیست. طبق دستور Phase 1، تمام کروموزوم‌های یک دیتاست دقیقاً یک مجموعه جایگاه دارند. گزینه قدیمی section_limits فقط اگر برای هر درس ذکرشده همان مقدار floor(Demand/MinSectionSize) را تکرار کند پذیرفته می‌شود؛ تغییر سقف به‌ازای کروموزوم رد می‌شود. override آزمایشی قبلی کنار گذاشته شده است. شرط حداقل اعضای گروه فعال بعداً در ارزیاب جواب سنجیده می‌شود. نام جایگاه‌ها با حذف/فعال‌سازی گروه دیگر بازشماری نمی‌شوند؛ حذف خود جایگاه یا افزودن جایگاه تازه خطای ساختاری است.

## تغییر، کپی و امتیاز

- `replace_section`: جایگزینی مشخصات جایگاه موجود، بدون تغییر درس یا شناسه آن؛ نمره‌ها را None می‌کند.
- `assign`: ثبت گروه فعال همان درس یا None برای یک درخواست موجود؛ نمره‌ها را None می‌کند. محدودیت ظرفیت و زمان در ارزیاب آینده است.
- `clone`: کپی مستقل برای فرزند؛ نمره فرزند از ابتدا None، نمره والد حفظ می‌شود.
- `section_sizes`: محاسبه تعداد اعضا از enrollments؛ تعداد عضو ژن مستقل نیست.
- `record_evaluation`: محل ثبت خروجی ارزیاب آینده، hard≥0 و soft در [0,1]. هنوز ارزیابی واقعی انجام نمی‌دهد و ثبت عدد به معنی معتبر بودن نیست.

نگاشت‌های عمومی و ذخیره داخلی نگاشت‌ها فقط‌خواندنی هستند؛ تغییر مستقیم دیکشنری و ویرایش SectionGene مجاز نیست. سازنده از دیکشنری‌های ورودی نسخه مستقل می‌گیرد؛ شناسه منابع هم فقط متن یا None هستند تا شیء تغییرپذیر به ژن راه نیابد. تغییر مجاز با ساخت snapshot جدید و invalidate_evaluation پیش از جایگزینی انجام می‌شود. ویرایش ردشده تغییری در داده و نمره نمی‌دهد. نماهای قبلاً گرفته‌شده snapshot قدیمی‌اند؛ برای مشاهده تغییر، property را دوباره بخوانید. این قرارداد API عادی است و دستکاری عمدی attribute خصوصی یا دورزدن frozen پایتون پشتیبانی نمی‌شود. فعال/غیرفعال‌سازی همراه بازتوزیع و Split/Merge اتمی هنوز عملگر جداگانه لازم دارند؛ این متدهای پایه جای آن عملگرها نیستند. پس از چند تغییر، validate_structure باید پیش از ارزیابی اجرا شود.

## مرز صحت ساختار و اعتبار جواب

`validate_structure` خطاهای شناسه، جایگاه اضافه/مفقود، section_id تکراری، تغییر درسِ جایگاه، گروه ناموجود/غیرفعال، درس اشتباه، کلید درخواست اضافی یا مفقود، تعداد جلسه نادرست، Slot ناشناخته یا تکراری، منابع ناموجود و کلید ناسازگار دیکشنری را برمی‌گرداند. گروه غیرفعال نباید استاد، اتاق یا جلسه داشته باشد. Slot موجود با IsAllowed=False از نظر ساختار قابل ارجاع است و منع استفاده‌اش در HardConstraintEvaluator بررسی خواهد شد. درخواست تکراری در Dataset Loader با محل دقیق رد می‌شود؛ builder نیز برای Dataset ساخته‌شده دستی قبل از تبدیل درخواست‌ها به دیکشنری دفاع مستقل دارد.

نداشتن خطای ساختاری به معنی پاسخ معتبر نیست: گروه با کمتر از ۸ نفر، منابع مشترک هم‌زمان، استاد فاقد صلاحیت برای درس، اتاق با نوع/تجهیزات نامناسب، زمان ممنوع، عدم حضور و حدود واحد/ساعت در ارزیاب قیود سخت بررسی می‌شوند. کروموزوم خالی ساختار سالم دارد ولی برنامه نهایی نیست. همه گروه‌های فعال به منابع موجود و جلسات کامل نیاز دارند، اما نیازی به وجود برنامه صددرصد معتبر از قبل ساخته‌شده نیست.
